# SkillSwap v5.3

SkillSwap 是一个中英双语技能交换社区。它希望让“我会什么”和“我想学什么”真正连接起来：用户可以展示自己能分享的技能、发现感兴趣的内容、匹配能力互补的伙伴，并完成从发起交换到实时沟通的完整流程。

在线体验：[https://skillswap-cefff752.demo.hack.microengine.org/](https://skillswap-cefff752.demo.hack.microengine.org/)

## 项目简介

SkillSwap 不把技能学习局限在传统课程中，而是鼓励社区成员互相教学、互相学习。例如，一位会摄影但想学习编程的用户，可以找到一位会编程但想学习摄影的伙伴，双方通过技能交换共同成长。

平台提供账号、个人资料、技能管理、搜索匹配、交换请求和实时聊天等功能。用户可以先完善自己的技能信息，再搜索或匹配合适的伙伴，向对方发送交换请求；双方建立连接后，可以继续通过站内聊天沟通学习内容和时间安排。

## 项目亮点

- **中英双语体验**：支持中文和英文界面切换，并保存用户的语言偏好。
- **互补技能匹配**：结合“我能提供的技能”和“我想学习的技能”，帮助用户发现更合适的交换伙伴。
- **完整交换流程**：支持发送、接受、拒绝、取消交换请求，以及双方确认完成。
- **实时文字聊天**：已连接的伙伴可以进行站内聊天，消息保存在 SQLite 数据库中，并通过 HTTP 长轮询及时同步。
- **资料与隐私控制**：用户可以维护个人介绍、所在地、技能和公开状态；未公开或资料不完整的账号不会进入公开搜索结果。
- **独立管理后台**：提供仅限服务器本机访问的管理员页面，用于管理用户、技能、会话和审计记录。
- **轻量化运行**：后端基于 Python 标准库，不需要安装第三方 Python 依赖；前端也不需要单独的打包步骤。
- **自动化测试覆盖**：测试覆盖认证、会话隔离、用户资料、技能、搜索、交换请求、聊天、管理员权限、安全校验和数据库迁移。

## 核心功能

- 用户注册、登录、退出和会话管理
- 个人资料、技能和隐私设置
- 双语技能目录与关键词搜索
- 互补技能伙伴发现与匹配
- 交换请求的完整状态管理
- 已连接伙伴之间的实时聊天与历史消息
- 社区统计与健康检查
- 本机管理员后台、权限控制和审计日志

## 技术结构

- **前端**：React 18、ReactDOM 18、Babel Standalone，集中在单个 `index.html` 中。
- **后端**：Python 3.10+ 标准库 HTTP 服务。
- **数据存储**：SQLite，用于账号、技能、交换请求和聊天数据。
- **管理后台**：原生 HTML、CSS 和 JavaScript。
- **字体资源**：仓库内置 HarmonyOS Sans SC Regular、Medium 和 Bold。

## 本地运行

项目不需要安装第三方 Python 依赖。在仓库根目录运行：

```bash
python server.py
```

然后打开：

- 用户端：`http://127.0.0.1:4173/`
- 管理后台：`http://127.0.0.1:4173/admin`
- 前端自测：`http://127.0.0.1:4173/?selftest=1`

首次启动时，程序会在 `data/` 目录中自动创建本地 SQLite 数据库。

## 部署说明

GitHub Pages 只能展示静态前端，不能运行 Python 和 SQLite 后端。需要使用账号、搜索、交换和聊天等完整功能时，请访问在线体验版本，或在本地运行 `server.py`。
