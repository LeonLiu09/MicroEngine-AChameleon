# SkillSwap 2.0 第一版反馈改进设计

日期：2026-08-16  
状态：待用户审阅  
实现边界：继续保持所有产品代码位于根目录 `index.html`，不增加后端或构建步骤。

## 1. 目标

本轮改版解决第一版预览中的八类问题：删除首页重复入口、优化流动技能标签、移除 SkillLoop、重构搜索筛选、统一人物卡片、分离 Search 与 Matches、将 Profile 升级为 Settings，以及用社区统计替代“技能社交画廊”。

改版后的体验应更短、更易理解，并明确区分三个核心目的：

- Discover 用于浏览社区动态和个性化内容。
- Search 用于主动查找技能或人物。
- Matches 用于管理已经产生关联的匹配、收藏与请求。

## 2. 已确认的视觉选择

- 流动标签：A「玫瑰同色系」。使用灰粉、豆沙、奶油白与少量梅子色。
- SkillLoop 替代模块：A「本周热门技能」。
- Settings 信息结构：C「完整设置」。

## 3. 首页与 Discover

### 3.1 首页入口

删除首页主视觉区中的“直接体验完整演示”“创建账户”“登录”按钮组。顶部导航继续保留创建账户和登录，因此访问路径不会丢失，也不会出现重复入口。

### 3.2 流动技能标签

技能池扩充到 28 种，覆盖技术、创作、语言、生活和运动。除现有技能外，加入 UI 设计、产品设计、咖啡拉花、烘焙、短视频制作、公众演讲、网球、书法、Excel、日语、法语、瑜伽、插画和基础理财。

两行标签保持反向流动，桌面和移动端共用同一技能池。动画时长由当前约 26/32 秒放慢到约 33/40 秒；鼠标悬停或键盘聚焦时暂停，并继续遵守 `prefers-reduced-motion`。

标签配色只使用玫瑰同色系 token，不再混入突兀的黄色、紫色和高饱和珊瑚色。交互标签仍需满足文字对比度与键盘焦点可见性。

### 3.3 Discover 热门技能

删除三人 SkillLoop 组件及其所有页面文案。Discover 底部替换为紧凑的“本周热门技能”模块，展示五项技能、关注/搜索人数和趋势条。点击技能进入 `#/search?q=<skillId>`。

当前没有后端，趋势数值使用固定演示数据：摄影 128、英语口语 96、Python 74、UI 设计 63、视频剪辑 51，并在模块中标记“演示趋势”。数值不伪装为实时统计。

### 3.4 首页社区概览

首页黑色卡片不再显示“技能社交画廊”。新卡片名为“社区概览”，显示“128 人在线、3,842 位用户、今日 46 次交换”。数据使用固定演示值并标注“演示社区数据”；未来接入后端时只替换数据来源，不改变组件结构。

## 4. Search

### 4.1 页面职责与空状态

Search 只负责主动搜索，不再默认复制 Discover 的推荐人物区。没有关键词和筛选条件时显示三个辅助区：最近搜索、技能分类、热门关键词。只有执行关键词搜索或设置筛选后才显示人物结果。

最近搜索仅保存在 SkillSwap 自己的本地状态中，最多保留五条，可逐条点击复用。技能分类与热门关键词来自固定技能数据。

### 4.2 筛选栏

控件顺序固定为：关键词、水平、国家、城市、语言、排序、重置。

国家必须先于城市选择。未选择国家时，城市控件禁用并显示“请先选择国家”；改变国家会清空不属于新国家的城市值。

国家列表以中国为首，并提供以下演示范围：

- 中国：北京、上海、天津、广州、深圳、杭州、成都、南京、武汉、西安。
- 美国：纽约、旧金山、洛杉矶、波士顿、西雅图。
- 英国：伦敦、曼彻斯特、爱丁堡。
- 加拿大：多伦多、温哥华、蒙特利尔。
- 澳大利亚：悉尼、墨尔本。
- 日本：东京、大阪。
- 韩国：首尔、釜山。
- 新加坡：新加坡。

删除“按姓名”“最佳匹配”排序。排序只保留：

- 最近发布：按 `publishedAt` 从新到旧。
- 最受好评：按 `likes` 从高到低；相同时以 `publishedAt` 新者优先。

筛选继续写入 Hash 查询参数，支持刷新、前进、后退和从资料页返回时恢复。

### 4.3 搜索结果卡片

所有卡片使用统一网格高度和固定底部操作区。技能描述较短时中间空间自动扩展，确保匹配标签、好评信息、发布时间和“查看资料”按钮在同一水平位置。

每张卡片始终显示一种关系说明：

- 存在互补技能时显示“双向交换 · XX%”。
- 没有互补技能但能教授目标技能时显示“可以教你：技能名”。
- 仅满足其他筛选条件时显示“符合你的筛选条件”。

卡片新增 `♥ <likes> 人好评` 与本地化发布时间。发布时间使用稳定日期数据，显示“今天”“2 天前”或完整日期，不随随机数变化。

## 5. Matches

Matches 不再复用 Search 的大人物卡片。页面采用通讯录式紧凑卡片，桌面双列、移动端单列，并分成三个区域：互补匹配、收藏的人、交换请求。

演示用户扩充到 12 人。每张通讯录卡片显示头像、姓名、国家/城市、能教的主要技能、想学的主要技能、匹配程度或请求状态。

每张卡片底部必须提供清晰、独立的“查看完整资料 →”按钮，不能只依赖点击整张卡片。

完整资料页包含：

- 个人简介与兴趣标签。
- 能教和想学的技能及水平。
- 语言、国家与城市。
- 可约时间和偏好的见面方式。
- 好评人数、可靠度、加入时间。
- 当前用户与此人的匹配原因。

资料页继续提供收藏和发送交换请求操作。

## 6. Settings

桌面与移动端主导航将 Profile 改为 Settings。`#/profile` 兼容重定向到 `#/settings`，避免旧书签失效。

Settings 首页先显示当前用户摘要和“查看公开资料”，再显示八个入口：

1. 个人资料与头像：修改头像、昵称、简介、国家和城市。
2. 技能与学习目标：复用现有技能编辑器。
3. 可约时间与地点：编辑时间段、线上/线下偏好和公共见面地点。
4. 通知设置：交换请求、收藏动态和提醒开关。
5. 隐私与安全：资料可见性、是否显示在线状态、仅允许公共地点开关。
6. 收藏的人：通讯录式显示已收藏用户，并可进入完整资料。
7. 帮助与反馈：常见问题和本地演示反馈表单。
8. 退出登录：只结束会话并返回首页，不删除个人资料或其他 SkillSwap 数据。

所有入口在 MVP 中均可操作，不放置无响应的占位按钮。

### 6.1 头像

头像选择支持 JPEG、PNG 和 WebP，原始文件上限为 5 MB。选择后立即预览；不支持的格式或超过上限时显示内联错误。保存前使用浏览器 Canvas 居中裁切为 256 × 256 像素，并以质量 0.86 的 JPEG Data URL 写入状态，避免把原始大图直接写入 `localStorage`。取消编辑不会覆盖当前头像。

### 6.2 设置持久化

设置继续写入 `skillswap-mvp-v1` 命名空间。状态规范化函数为旧数据补充缺失字段；解析失败时恢复安全默认值。重置演示仍只删除 SkillSwap 自己的数据。

## 7. 数据模型

用户种子记录新增或规范化以下字段：

- `countryId`、`cityId`
- `interests[]`
- `likes`
- `publishedAt`
- `availability[]`
- `meetingModes[]`
- `reliability`
- `memberSince`
- `avatarDataUrl`（仅当前用户可写）

应用状态新增：

- `recentSearches[]`
- `notificationSettings`
- `privacySettings`
- `feedbackEntries[]`
- `session.loggedIn`

种子数据保持不可变；用户操作通过新的状态对象持久化。所有人数、日期和趋势值均为确定性数据，测试和页面刷新不会随机变化。

## 8. 组件与路由边界

新增或调整的逻辑单元：

- `COUNTRIES` 与 `getCitiesForCountry()`：国家—城市联动。
- `SearchEmptyState`：最近搜索、分类和热门词。
- `SearchResultCard`：统一搜索结果布局。
- `ContactMatchCard`：Matches 通讯录卡片。
- `TrendingSkills`：Discover 热门技能模块。
- `CommunityStats`：首页演示社区概览。
- `SettingsHome` 与各设置面板：设置路由及表单。
- `normalizeUser()` 与 `normalizeState()`：兼容旧本地数据。

新增 Hash 路由使用 `#/settings/<section>`。未知设置子路由返回 Settings 首页并显示可恢复提示，不产生空白页。

## 9. 错误处理与无障碍

- 国家改变时主动清除无效城市，不保留隐藏筛选条件。
- 没有搜索结果时显示当前条件摘要和清除筛选按钮。
- 图片读取或缩放失败时保留旧头像，并显示可关闭错误。
- 设置表单保存成功后显示状态提示；未保存离开时不写入数据。
- 所有新按钮、下拉框和开关支持键盘操作、清晰标签和可见焦点。
- 动画遵守减少动态效果设置。
